# Exemplars

"이 스타일로 쓰면 된다"는 레퍼런스 코드 모음. 신규 코드를 생성할 때 이 파일들의 구조/애노테이션 순서/네이밍을 **거울처럼 따른다**.

## 현재 등록된 모범 예시

| 레이어 | 파일 | 쓰임 |
|--------|------|------|
| Entity | `User.java` | BaseEntity 상속, Builder, 상태 메서드 패턴 |
| Controller | _추후 추가_ | - |
| Service | _추후 추가_ | - |
| Repository | _추후 추가_ | - |
| DTO | _추후 추가_ | - |

## 갱신 규칙

- 각 도메인의 **첫 번째 수직 슬라이스**가 완성되면 대표 파일을 여기 복사/동기화
- exemplar는 실제 코드와 드리프트가 생기면 의미 없음. 슬라이스 구현 완료 시점에 함께 갱신
- 원본 파일을 직접 링크해도 되지만 (symlink 관리 이슈), 복사본을 두고 갱신일자를 댓글로 남기는 편이 안전
