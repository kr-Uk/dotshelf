product direction

사용자는 책장을 보고 사람을 이해합니다

dotshelf의 첫 화면은 콘텐츠 목록이 아니라 방입니다. 사용자는 책장, 노트북, 방명록을 오가며 상대의 취향과 기록을 천천히 살펴봅니다.

공간 먼저 쿼터뷰 방에서 시작해 책장, 대시보드, 방명록으로 자연스럽게 이동합니다.
슬롯 기반 배치 책 이동은 물리 낙하가 아니라 명확한 슬롯 삽입과 미리보기 상태를 따릅니다.
따뜻한 사실감 현실적인 책장과 부드러운 조명으로 아늑하지만 기능적인 분위기를 만듭니다.

interactive preview

MVP 핵심 화면 흐름

Quarter View

방 전체에서 내 서재를 한눈에 봅니다

사용자는 따뜻한 3D 방에 들어와 책장, 노트북, 방명록 위치를 먼저 파악합니다. 첫 화면부터 dotshelf가 책 기반 공간 서비스라는 점이 드러납니다.

  • 책장, 대시보드, 방명록을 같은 방 안에 배치
  • PC와 태블릿에서 쿼터뷰 중심 탐색
  • 공간 오브젝트 클릭으로 기능 진입

shelf and book

책장 편집은 명확하고 되돌리기 쉬워야 합니다

책장 담당 영역은 사용자가 가장 오래 만지는 곳입니다. 그래서 이동, 삽입, 이름 변경, 디자인 변경이 모두 예측 가능한 상태 전환으로 보여야 합니다.

drag

중간 삽입 가능한 책 이동

책을 마지막에만 붙이는 흐름이 아니라 원하는 슬롯 사이에 끼워 넣는 배치를 지원합니다.

edit

편집 모드

이름 변경, 책장 추가와 삭제, 디자인 변경을 일반 탐색과 분리해 실수 가능성을 낮춥니다.

focus

줌 기준 책 포커싱

책을 선택하면 현재 줌 정도에 맞춰 너무 앞으로 튀어나오지 않는 위치로 포커싱합니다.

preview

미리보기 상태

드래그 중에는 슬롯 후보만 강조하고, 확정 전에는 실제 도메인 데이터를 바꾸지 않습니다.

core loop

방문에서 기록까지 이어지는 흐름

dotshelf의 핵심 루프는 방을 구경하고, 책을 열어보고, 기록을 남기고, 다시 책장으로 돌아오는 짧은 반복입니다.

  1. 1 서재 입장

    쿼터뷰 방에서 책장과 소셜 오브젝트를 확인합니다.

  2. 2 책장 탐색

    스크롤 줌과 섹션 이동으로 원하는 책을 찾습니다.

  3. 3 책 상세

    독서 상태, 기록, 리뷰 진입점을 같은 패널에서 확인합니다.

  4. 4 소셜 연결

    방명록과 피드로 상대의 독서 세계에 짧게 반응합니다.

mvp scope

첫 배포에서 보여줄 것

MVP는 모든 독서 기능을 넓히기보다, dotshelf만의 첫인상인 3D 책장과 책 기반 정체성을 선명하게 보여주는 데 집중합니다.

책장

책

기록
읽는 상태와 감상 기록을 책 상세 흐름에 연결
소셜
방명록과 피드로 조용한 방문 경험 제공
